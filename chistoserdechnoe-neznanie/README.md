# Чистосердечное незнание

Шуточная страница оперативного штаба по поиску участников группы, пропавших после блокировки Telegram.

## Посмотреть

Готовая версия: https://chistoserdechnoe-neznanie.gurov86rus.chatgpt.site

## Запустить локально

```bash
npm install
npm run dev
```

После запуска страница откроется на http://localhost:3000.
